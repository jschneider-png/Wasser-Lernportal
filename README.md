# Wasser-Lernportal
Interaktives Wasser-Lernportal für SHK mit Themen zu Grundlagen Wasser, Trinkwasser, Wasserhärte, pH-Wert und TOC. Drei Schwierigkeitsstufen mit Multiple Choice, Zuordnungs- und Rechenaufgaben, direkter Rückmeldung und Fortschrittsanzeige. Ideal für selbstständiges Lernen und Wiederholen.
